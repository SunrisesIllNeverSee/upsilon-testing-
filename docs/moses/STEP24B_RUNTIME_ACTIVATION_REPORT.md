## 4. Independence proof

### SOURCE/PARSER
- `StructuredMutation` produced by `semantic_mapper.map_instruction` from parser-extracted section-level instructions
- `mutation_to_evidence` converts mutation to `AmendmentEvidence` with `PARSER_EXTRACTED` provenance
- Source text span is traceable to amendment filing text

### S0 AUTHORITY
- `IssuerChain.s0_section_refs` provides section→commitment mapping from the source agreement (S0)
- `AgreementAddressMap` populated from `s0_section_refs`, NOT from amendment target labels
- Prefix/suffix matching handles granularity differences (e.g., "Section 7.10" → "Section 7.10(a)")

### PREDECESSOR STATE
- Engine resolves identity first, then selects predecessor from resolved commitment_id
- `AffectedField.old_value` = predecessor actual value (C_{t-1}[field])
- `AffectedField.amendment_declared_old_value` = old value stated in amendment (independent)

### CURATION / EVALUATION ONLY
- `CURATOR_PROVIDED` values require corroboration against source text
- `canonical_key_hint` is weak corroboration only — cannot establish identity alone
- Ground truth used only in measurement/audit layer, never imported into runtime code
