# Archived Prompts - Upsilon/MOSES

This directory preserves the full text of step prompts supplied by the
user so that future agents have the complete specification without
relying on session context.

## Index

| File | Step | Status |
|------|------|--------|
| `STEP_23M.md` | Phase VI, Step 23M - MOSES Semantic Control Architecture Package | Base prompt |
| `STEP_23M_ADDENDUM.md` | Step 23M addendum - Original MOSES Commitment Architecture as Controlling Anchor | Addendum to base |
| `STEP_23M_CONSTRAINTS.md` | Step 23M execution clarification - Six controlling constraints | Constraints on base |
| `STEP_23S.md` | Phase VI, Step 23S - MOSES Semantic Safety Enforcement | First runtime enforcement step |

## Conventions

- Prompts are archived verbatim (ASCII-safe substitutions for non-ASCII
  characters where needed for portability).
- If the user supplies a revised prompt, archive the revision as a new
  file (e.g. `STEP_23M_v2.md`) rather than overwriting.
- Do not modify archived prompts without explicit user authorization.
- The authoritative execution order is: base prompt, then addendum, then
  constraints.  All three apply simultaneously.
